# 系統欄位與版本規則

## 暫行欄位
本檔為寫作輔助，不是正式系統選單。基本資訊可列時間、實際接觸對象、接觸方式及地點；未提供者 OOO，電話接觸不可自行填入案家訪視地點。

| 類型 | 記錄方式 | 限制 |
| --- | --- | --- |
| 接觸方式 | 電話、實體訪視等實際方式 | 接觸方式不等於可計入的服務項目 |
| 已執行服務 | 描述確實執行的行動及證據 | 建議、預計轉介不算已完成 |
| 正式服務項目 | OOO（待確認系統版本及正式選單） | 不從自立後追清單移植逆境分類 |
| 本次目標 | 引用原目標；未提供填 OOO | 不追溯捏造 |
| 年度／地方／表單版本 | 各別記錄，未知 OOO | 不跨版本合併欄位 |

## 電話關懷與心理治療
「電話詢問近況、傾聽困擾」只能記錄實際電話關懷或支持作為；不能因談到情緒便判定心理治療。心理治療須有實際專業服務、提供者及服務紀錄等佐證，且正式計入仍須核對該年度系統定義。轉介心理服務不等於已接受心理治療；未知項目標 OOO（待社工核對）。

## 文件補齊後
為每一年度、地方及版本各建欄位對照，記錄原名稱、頁碼、定義、計入條件、生效範圍及差異。衝突時並列差異，交由主管確認適用版本，不自行選最新版或混用。
